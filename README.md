# Mini Lisp Interpreter

A small Lisp interpreter written in Haskell, exploring the fundamentals of parsing, expression evaluation, and programming language implementation.

## What it does

Parses basic Lisp expressions into an internal representation and evaluates them using an environment of built-in procedures.

## Example

```lisp
(+ 3 5)
```

```haskell
Number 8
```

## Status

Basic parsing, environment lookup, and primitive procedure application are implemented. Nested expressions are the next step.
